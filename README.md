# My Dev Portfolio

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen)](https://devugs.net)

---

## Description

My personal portfolio web app where you can find my development projects and the technologies I use. Built with **JavaScript, React, Tailwind CSS, Express, HTML**, and **MongoDB**, it is fully responsive and deployed on **Render**.

---

## Features

- Dynamic multi-language support **(English & Spanish)** using React Context  
- Responsive and mobile-friendly design with **Tailwind CSS / CSS3**  
- GitHub references and live links for projects
- Integrated contact form with **mailing** functionality
